# 🎸 Air Guitar AI Studio

Real-time Computer Vision Virtual Guitar powered by **OpenCV**, **MediaPipe Hand Tracking**, **FastAPI**, and **WebSockets**.

## ✨ Features
- **Real-Time Hand Tracking:** Detects finger positions, strumming gestures, and fret chords via webcam.
- **FastAPI + MJPEG Stream:** Low-latency live video feed with HUD overlays.
- **WebSocket Telemetry:** Instant push of chord/strum events to the web synthesizer UI.
- **Interactive Guitar Engine:** Real-time audio synthesis and visual fretboard feedback.

## 🚀 Quick Start
```bash
pip install -r requirements.txt
python main.py
```
